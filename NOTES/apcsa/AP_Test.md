# MCQ tactics

1. Aim for 2 minutes per question
2. Prioritize questions:
    - Know you strong topics
        - (get warmed up)
    - Avoid / skip long complex questions the first time you see them
        - Roman num. (I, II, III, ...)
        - Long code segments
3. Read the full question (RTFQ) before reading any code segement
4. Eliminate any wrong answers
