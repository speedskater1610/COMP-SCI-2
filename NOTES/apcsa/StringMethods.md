# String Methods

Most `String` methods are **instance methods** which means that they called on `String` variables and are held in memory on the `String`.

Common Methods include

- `.charAt(index)` -> `char`
- `.indexOf(String or char)` -> `int`
- `.length()` -> `int`
- `.substring(startIndex)` -> `String`
- `.substring(startIndex, stopIndex)` -> `String`
- `.toUpper/LowerCase()` -> `String`
