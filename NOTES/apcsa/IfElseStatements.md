# `If` / `Else` statements

```java
if (Condition / Boolean) {
    // code to run
}
else {
    // Optional
}
```


You are able to run an if statement on a boolean variable, so for example assuming you have a boolean variable called `doorOpen`

```java
if (doorOpen == true); // redundant don't do this
if (doorOpen);
```

## Nesting
```java
if (A) {
    if (B) {
    
    } 
    else {
    
    }
}
```
